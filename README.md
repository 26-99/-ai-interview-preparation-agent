# AI Interview Preparation Agent

## Project Overview
An AI-powered interview preparation agent built using n8n and Google Gemini. It helps students and fresh graduates prepare for technical interviews with structured, role-specific guidance.

## Problem Statement
Preparing for technical interviews can be challenging for fresh graduates. This project provides relevant questions, beginner-friendly answers, important study topics, and a short preparation plan to make preparation more organized.

## Technologies Used
- n8n — Workflow automation
- Google Gemini — AI language model
- AI Agent — Interview preparation logic

## Workflow
Chat Message Input → AI Agent → Google Gemini Chat Model → Interview Preparation Response

## Key Features
- Generates five relevant technical interview questions with beginner-friendly answers.
- Recommends three important topics to study.
- Creates a three-day study plan.
- Provides confidence tips for interviews.

## How to Use
1. Open the AI Interview Preparation Agent through the available n8n chat interface.
2. Enter a job role, such as Java Developer.
3. Optionally mention skills such as Java, SQL, Spring Boot, and REST APIs.
4. Review the generated questions, answers, topics, study plan, and confidence tips.

## Example Input
Prepare me for a Java Developer interview. My skills are Java, SQL, Spring Boot, and REST APIs.
